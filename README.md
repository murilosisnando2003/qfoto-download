# QFoto: download

Instalador do **QFoto**, programa para Windows que separa fotos por rosto.
**Encontre. Organize. Compartilhe.** Site: https://qfoto.com.br

**Baixe sempre pela página do site:** https://qfoto.com.br/baixar

- Windows 10 ou 11, 64 bits. 16 GB de memória recomendados.
- O programa precisa de uma **chave de ativação**. Peça a sua em https://qfoto.com.br/#comprar.
- Ao instalar, você aceita os [Termos de uso](https://qfoto.com.br/termos).
- 100% local: nenhuma foto sai do seu computador.

Este repositório contém só os instaladores, publicados em *Releases*. O código-fonte do QFoto é privado.
